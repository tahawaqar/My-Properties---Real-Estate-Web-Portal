# My-Properties---Real-Estate-Web-Portal
The "My Properties" project is a responsive, single-page web application designed for a real estate agency. The primary goal is to showcase luxury property listings, describe available services, and provide a seamless way for potential buyers to contact the agency through an integrated lead-generation form.

Technical Stack
The project utilizes the core "Trinity of Web Development":
•	HTML5: For semantic content structure.
•	CSS3: For styling, responsive grid layouts, and visual transitions.
•	JavaScript (ES6): For implementing scroll-triggered animations (Intersection logic).
